# Templates

## Purpose

Placeholder for reusable file/config templates (e.g. Ansible Jinja2
templates, `.tfvars.example`, Kubernetes manifest examples) used by
automation across this repository.

## Scope

Covers reusable, parameterized templates. Does not cover static, ready-to-
use configuration — see [configs/README.md](../configs/README.md).

- [docs/automation/ansible.md](../docs/automation/ansible.md)

## Status

**Not yet implemented.** Contents will be added alongside the automation
that consumes them (Ansible roles, Terraform/OpenTofu examples).
