# Tools

## Purpose

Placeholder for helper/developer tooling used to work on this repository
itself (e.g. documentation linters, link checkers), as distinct from
tooling installed onto the workstation for application development.

## Scope

Covers meta-tooling for repository maintenance. Does not cover the
workstation automation itself — see [ansible/](../ansible/README.md),
[docker/](../docker/README.md), and [scripts/](../scripts/README.md).

## Prerequisites

None.

## Status

**Not yet implemented.** Candidate additions: a Markdown link checker and a
Markdown lint configuration to keep documentation consistent, to be wired
into [.github/workflows](../.github/workflows).
